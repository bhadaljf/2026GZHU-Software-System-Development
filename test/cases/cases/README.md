### 2.4 统一推演口径

1. **批次顺序**：1→2→3→4；前批已录取者立即退出后续批次。
2. **批内顺序**：先高梯度，后低梯度；同一梯度内先第 1 志愿轮次，再第 2 志愿轮次，依次推进。禁止逐人扫描全部志愿。
3. **同一志愿轮次**：对报考同一计划且尚未录取、满足资格与分数要求的考生，按总分降序、同分序号升序录取至满额。
4. **自主招生**：先过滤“填报该校 + 在资格名单内 + 总分 ≥ 该计划控制线”，再按考核排名升序录至满额。考核排名是校内排名，不与中考总分混用。
5. **名额分配**：以“高中—初中”为名额单位；考生只能进入自己初中对应的候选池，不得跨校。
6. **结转**：第一、第二批结束后，先汇总 A/B 各自的第一批余额和各初中第二批余额，再一次性转入本校第三批统招；只结转一次。任务书 §三.4 明确写的是“第一、第二批结束后”，U06 只细化了第二批的汇总方式，因此本稿将第一批余额也计入 `carry_in`；见 A-02。
7. **统计**：`min_score` 是该计划已录取考生总分最小值；`last_student` 是按 `admit_order` 最后录取的人；二者独立。无人录取时 `min_score`、`last_student`、`last_score` 均为字符串 `"无"`，`last_vol_seq` 为 `null`。
8. **`admit_order`**：一次完整运行内全局递增，从 1 开始；同一梯度、同一志愿轮次内，按计划 ID 升序处理不同计划。该顺序只影响 `admit_order` 的展示，不改变任何计划的录取集合；见 A-05。
9. **空值**：计划控制线、名额所属初中等不适用字段用 `null`；不把“无”写成 0。
10. **志愿空缺**：`vol_seq` 允许不连续，空缺表示未填该志愿；c04 用“低 1 分者第 1 志愿、压线者第 2 志愿”放大边界差异，见 A-06。
