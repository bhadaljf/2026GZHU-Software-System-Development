实体关系说明：
- middle_school（初中）一对多 student（考生），一名考生归属一所初中
- high_school（高中）一对多 plan（招生主计划），一所高中有多条招生计划
- plan（主计划）一对多 quota_plan（名额分配子计划），一条主计划可以拆分多条名额分配子计划，定向分配给不同初中
- student（考生）多对多 high_school（高中），通过 self_recruit_eligibility 记录自招资格
- student（考生）一对多 volunteer（志愿），一名考生填报多条志愿
- plan（招生计划）一对多 volunteer（志愿），一条计划可被多名考生报考

## 3 约束与索引
唯一约束、外键、按访问路径建的索引，说明每个索引服务的查询。

### 约束汇总
1. 外键约束：全部外键开启引用检查，保证引用的主键记录存在。
2. 检查约束
- high_school.recruit_batch 仅允许取值3、4
- plan.batch 仅允许取值1、2、3、4
- plan.category 仅允许 self_recruit、quota、unified
- plan.quota >= 0
- plan.control_line >= 492
- plan.remaining >= 0
- quota_plan.quota >= 0
- volunteer.seq > 0

### 索引列表
| 索引名称 | 索引字段 | 索引类型 | 用途说明 |
| ---- | ---- | ---- | ---- |
| idx_middle_name | middle_school(name) | 唯一索引 | 防止初中名称重复，按校名快速检索初中 |
| idx_high_name | high_school(name) | 唯一索引 | 防止高中名称重复，按校名快速检索高中 |
| idx_student_score_tieseq | student(score, tie_seq) | 唯一索引 | 同分场景下，按分数+同分序号排序、比对优先级 |
| idx_plan_uniq | plan(year, high_school_id, batch, category) | 唯一索引 | 避免同一年、同一高中、同一批次、同一类别重复建计划 |
| idx_selfrecruit_high_rank | self_recruit_eligibility(high_school_id, rank) | 唯一索引 | 同一高中内自招考核排名不重复，按排名顺序检索自招考生 |

## 4 数据字典
字段级说明，含枚举取值（批次、类别、状态）。

1. recruit_batch（高中统招接收批次）
取值：3、4
含义：该高中可以接收统招投档的批次。

2. batch（计划批次 / 志愿批次）
取值：1、2、3、4
含义：录取批次，1为自招批，2为名额分配批，3、4为统招批。

3. category（计划类别）
取值：self_recruit、quota、unified
self_recruit：自主招生计划
quota：名额分配计划
unified：统招计划

4. status（自招资格状态）
取值：ok、invalid
ok：资格有效，可以参与自招投档
invalid：资格无效，不参与自招投档

## 5 计划切分与余额对账
总计划 → 第一批（≤10%）→ 名额分配（50%）→ 第三批余额；有效计划数＝初始计划＋转入。

### 对账逻辑说明
1. 总计划基数：plan.quota 为本条计划初始名额。
2. 第一批（自招批）名额上限：不超过总计划的10%，从总计划中切分。
3. 名额分配（第二批）名额：占用总计划的50%，分配到各个初中，存入quota_plan。
4. 第三批余额：总计划扣除自招、名额分配已切分名额之后，剩余可用于统招批次的名额。
5. 有效计划数计算公式：有效计划数 = 初始计划名额 + 转入名额
6. 余额字段 plan.remaining 实时记录当前计划剩余可投档名额，每录取一名考生，余额扣减；有转入名额时余额增加，用于对账校验，保证录取流程名额不超。
