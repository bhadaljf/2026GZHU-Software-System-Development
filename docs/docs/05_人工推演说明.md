# 05 人工推演说明（第 1 阶段骨架）

> 角色：5 号“测试与验证”。
> 阶段：第 1 阶段（11.16—11.22）首版。
> 状态：12 类用例清单与 6 个核心 case 的人工预期已完成；本文只记录推演方法、数据来源、映射、未覆盖边界与核验记录。不包含 harness、测试引擎、滑档前后对比、部署复现。
> 预期来源：全部为手工推演。未调用任何投档引擎，未用系统输出反推预期。只使用只读脚本核对 JSON 语法、守恒式和统计字段，不生成新的录取结果。

## 1. 推演原则

1. **先预期后系统**：先固定参数、计划、考生、志愿、资格，再逐轮写出“谁录、谁不录、余额从 x 变 y”，最后才允许第 2 阶段拿系统结果对照。第 1 阶段不运行系统。
2. **每一步可指回条款**：每个录取/跳过动作至少标注一个来源：任务书章节、统一规则编号（U01—U10）或本组规则编号（R1—R10）。指不回去的结论不写成确定预期，放入契约歧义清单。
3. **批次—梯度—志愿轮次三层锁死**：先确定批次，再确定梯度，再确定志愿轮次；同一轮次内才比较总分和同分序号。禁止“逐人扫描全部志愿”。
4. **名额单位不混用**：名额分配以“高中—初中”为单位；统招才允许全体考生竞争。跨初中志愿不进入候选池，不能以“分数更高”为由挤占。
5. **结转只做一次**：第一、第二批全部结束后，先按高中汇总第一批余额和各初中第二批余额，再一次性转入本校第三批；第三、第四批余缺不互转。
6. **统计分开算**：最低录取分取“已录取总分最小值”；末位考生取“实际录取顺序最后一人”；两者不得互相代替。无人录取返回“无”，不返回 0。
7. **交叉核对**：每个 case 至少做三类核对：
   - 逐轮余额与最终余额表一致；
   - `initial + carry_in − carry_out = admitted + remaining`；
   - 汇总统计与录取明细一致（人数、最低分、末位考生）。
8. **宁可标缺口，不硬凑**：数据不足以验证的场景，在“没验证什么”中明说，并列入第 2 阶段计划；不用一个 case 冒充多个场景。

## 2. 小数据集与参数来源

### 2.1 参数

| 参数 | 值 | 来源 |
|---|---:|---|
| `L` | 600 | 题设示例；任务书 §五最低测试示例也用 600 |
| `G1` | 720 | 题设示例；任务书 §五最低测试示例也用 720 |
| `delta` | 40 | 题设与任务书 §三.1 默认值 |
| 第二梯度线 | 680 | `720 − 40` |
| 第三梯度线 | 640 | `720 − 2×40` |
| 第四梯度线 | 600 | `720 − 3×40`，等于 L |

所有六个核心 case 使用同一组参数；没有 case 另设全局参数。A-Z1、B-Z1 的计划控制线 680、660 是计划级输入，不是全局参数。

### 2.2 学校与计划

- 2 所初中：J1、J2。
- 4 所高中：A、B 为第三批且有第一批自招、第二批名额分配；C 只在第四批；D 只在第三批统招。
- A 总计划 10 = 自招 1 + 名额分配 5（J1 3、J2 2）+ 第三批统招 4。
- B 总计划 10 = 自招 1 + 名额分配 5（J1 2、J2 3）+ 第三批统招 4。
- C 总计划 1，第四批统招；D 总计划 1，第三批统招。
- 完整计划表、20 人名册和参数边界见 `test/cases/README.md`。

**已披露的数据集偏差**：按 10% 上限与 50% 名额分配同时取整、且自招至少 1 人，最小总计划为 10，第三批统招只能为 4；这与题设“每条计划 1—3 人”冲突。本稿优先执行硬规则 2 的 10%/50%，把 4 人作为已披露偏差 A-01，没有暗改数字。若 1 号确认可对 10% 向上取整，则应改为总计划 8、自招 1、名额 4、统招 3；届时要重算全部 `carry_in` 与余额，但 c02/c03/c04/c05/c10 的录取归属预计不变，c08 的余额数字会变。

### 2.3 数据来源与边界

- 规则来源：课程任务书 §二、§三、§四.3、§五；本组统一规则 U01—U10。
- 参数来源：题设示例 + 任务书 §五最低测试示例（G1=720、第二梯度=680、L=600）。
- 考生、姓名、分数、同分序号均为虚构，不对应真实个人。
- 不引入户籍、区外生、加分、民办/中职、补录、退档、报到注册等已简化内容。

### 4.2 已知但暂不展开的口径

- 自招未满余额转入第三批后，控制线取“原自招线”“第三批计划线”还是“两者较严”（A-03）。

- `expected.json` 固定字段没有 `last_tie_seq`，末位同分序号只能写在 `case.md`（A-07）。
