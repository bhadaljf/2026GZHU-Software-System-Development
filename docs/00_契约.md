## 3 原因码

| 码 | 含义 | 适用批次 |
| --- | --- | --- |
| R01 | 未达计划控制线或最低控制线 L | 全部 |
| R02 | 计划名额已满 | 全部 |
| R03 | 不在自主招生资格名单或排名不达 | 第一批 |
| R04 | 前批已录取 | 第二至第四批 |
| R05 | 非所属初中名额 | 第二批 |
| R06 | 志愿或计划无效 | 全部 |
| R07 | 未填报该计划 | 全部 |

实现位置：`src/query/reasons.py`（4 号），文案与码值以此表为准。

## 5 口径约定

1. 最低录取分（R30）与末位考生（R31）分别计算，可以不是同一人；两字段各自独立返回。
2. 无人录取时二者返回 `null`，界面显示“无”，不得写 0（R32）。
3. 分数一律为整数；时间一律 ISO 8601；金额类不涉及。
4. 名额守恒以 `plan.quota + 转入 − 转出 = 已录 + plan.remaining` 为准（R27）。
