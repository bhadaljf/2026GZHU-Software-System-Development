## 1 表结构摘要

| 表 | 主键 | 关键字段 | 约束 | 负责人 |
| --- | --- | --- | --- | --- |
| middle_school | school_id | name, district | 名称唯一 | 2 号 |
| high_school | school_id | name, type, recruit_batch | 统招批次取 3 或 4 | 2 号 |
| student | student_id | name, junior_school_id, score, tie_seq | 同分序号校内唯一 | 2 号 |
| plan | plan_id | year, high_school_id, batch, category, quota, control_line, remaining | 年度+高中+批次+类别唯一 | 2 号 |
| quota_plan | plan_id, junior_school_id | quota | 二批专用，名额到校 | 2 号 |
| self_recruit_eligibility | student_id, high_school_id | status, rank | 排名校内唯一 | 2 号 |
| volunteer | year, student_id, batch, seq | plan_id | 同批次同序号唯一 | 2 号 |
| run | run_id | year, params_json, data_version, operator, created_at | — | 1 号 |
| admit_result | result_id | run_id, student_id, plan_id, batch, volunteer_no, admit_order | 每生每 run 最多一条 | 3 号 |
| admit_log | log_id | run_id, batch, band, volunteer_no, plan_id, student_id, action, reason_code, balance_before, balance_after | — | 3 号 |

## 2 录取结果表字段（admit_result）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| run_id | text | 运行编号，外键到 run |
| batch | int | 1—4 |
| plan_id | text | 录取计划 |
| student_id | text | 考生 |
| score | int | 录取时总分 |
| tie_seq | int | 同分序号 |
| volunteer_no | int | 该考生被录的志愿序号 |
| admit_order | int | 该计划内的录取顺序，从 1 开始 |

## 3 投档日志表字段（admit_log）

见上表；`action` 取 `admit` / `skip`，`reason_code` 见第 4 节。跳过记录按“原因 + 计划”汇总计数，录取记录逐条保留。

## 4 原因码

| 码 | 含义 | 场景 |
| --- | --- | --- |
| R01 | 未达计划控制线或最低控制线 L | 全部批次 |
| R02 | 计划名额已满 | 全部批次 |
| R03 | 不在自主招生资格名单 | 第一批 |
| R04 | 前批已录取 | 第二至第四批 |
| R05 | 非所属初中名额 | 第二批 |
| R06 | 志愿或计划无效 | 全部批次 |
| R07 | 未填报该计划 | 全部批次 |
