## 5. 依赖契约尚未明确口径的结论

- **A-05（A/B 两校自招的全局顺序）**：S18 的顺序 1、S20 的顺序 2 来自“同一批内按计划 ID 升序处理”。两校自招名额互不竞争，若改为 B 先 A 后，录取集合不变，只是顺序数字互换。
- **A-03（自招未满余额结转）**：本 case 两条自招均满额，`carry_out=0`，所以不触发“自招余额转入第三批后适用哪条控制线”的歧义；该歧义留给第 2 阶段专门 case。
- **A-01（计划切分）**：A-Z1 1/10=10%、B-Z1 1/10=10%，与 10% 上限吻合；但总计划 10 导致 A/B 第三批统招 4 人，与 1—3 人冲突，见 README A-01。
- **A-04（同分序号范围）**：S18 与 S03 同为 710 分，但自招按考核排名，不用同分序号；本 case 不验证同分序号的全市/校内范围。
- **A-07（JSON 未含末位同分序号）**：A-Z1 末位 S18 序号 18、B-Z1 末位 S20 序号 20，只在 `case.md` 表中报告。
