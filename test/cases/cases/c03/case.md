#### 第 2 梯度（T2，680—719）

**第 1 志愿轮次**（依据 §三.3；U04；R4、R6）：

1. **A-Q-J2 候选池筛选**：
   - S05（J2，700，seq5）：有效；

   - S07（J2，690，seq7）：有效；

## 4. 本 case 验证了什么、没验证什么

### 4.1 验证了什么

- 同梯度、同志愿轮次内先比总分：700 > 690，S07 排在两名 700 分之后。
- 同分时比同分序号：S05(seq5) 先于 S19(seq19)；若按序号降序或按输入顺序，顺序会反转。
- 名额分配的“高中—初中”隔离：S04 是 J1、700 分、序号 4，若系统错误地允许其进入 J2 候选池，他会凭 700/seq4 排到 S05 前面并挤掉 S19；本 case 的预期正是防止这种跨校挤占。
- 计划余额 2→0，S07 不因“分数高”被强行塞入。

### 4.2 没验证什么

- **跨批次排除**：本 case 无第一批录取者，不能证明已录者退出；由 c06 验证。
- **名额结转重复执行**：本 case 的 A-Q-J2 已满，A-T 的转入只来自空名额；重复执行不增额由 c08 验证。
- **末位≠最低**：本 case 两者恰好相同；由 c10 验证。
- **同分序号唯一范围的全市/校内口径**：本 case 的同分双方都是 J2；跨初中同分竞争未覆盖，见 A-04。
- **越界志愿应在校验阶段拒绝还是运行中跳过**：本 case 采用“跳过并记原因码”，见 A-08；若 1 号确认应拒绝整个运行，则本 case 的 2 条录取仍不变，但 S04 的呈现位置改变。

> 结论：c03 的数据足以验证“同分序号小者优先”和“J2 名额不被 J1 挤占”；不足以单独验证跨批次与结转重复执行，这些没有被硬凑进本 case。
