# c05 自主招生：资格、计划控制线与考核排名

> **规则依据**：任务书 §三.2“仅对填报该校、在其资格名单内、且总分达到计划控制线的考生，按输入的考核排名从前到后录取至满额；考核排名应在该校内唯一”；U05；R5。
> **参数**：`L=600`，`G1=720`，`delta=40`。A-Z1 计划控制线 680；B-Z1 计划控制线 660。
> **数据切片**：A、B 两所高中的自主招生各 1 个名额；每校 4 名相关考生，共 8 人。全部只填第一批志愿。
> **不在本 case 验证**：统一招生梯度、名额分配、跨批次排除、统计口径差异。

## 2. 人工推演

### 2.0 推演前检查

- 自主招生不使用梯度轮次；按 §三.2 先过滤“填报 + 资格 + 达到计划控制线”，再按考核排名。
- 考核排名是校内排名，A 校与 B 校的排名不能放在一起比较。
- A 校：S10 排名 1 但 679 < 680，不能录；S18 排名 2、S03 排名 3 均达标；S04 无资格。
- B 校：S15 排名 1 但 659 < 660，不能录；S20 排名 2、S11 排名 3 均达标；S07 无资格。

### 2.1 第一批

#### A 校 A-Z1（计划 1 人；控制线 680）

1. **过滤志愿**：S10、S18、S03、S04 均填报 A-Z1。
2. **过滤资格**：S04 不在资格名单，排除；S10、S18、S03 在名单内。
3. **过滤计划控制线**：S10 679 < 680，排除；S18 710、S03 710 达标。
4. **按考核排名**：S18 排名 2，S03 排名 3；S18 在前。
5. **录取**：A-Z1 计划 1 人，录 S18；S03 因满额不录。
   - 余额：1→0。
   - 全局录取顺序：S18=1。
   - 依据 §三.2；U05；R5。

> 关键点：S10 是校内考核排名第 1，但总分未达计划控制线，不能因为“排名最高”被录；排名第 2 的 S18 递补。这里先做资格/分数过滤，再排名，不是先按排名占名额再补条件。B 校同理：S15 排名第 1 但 659 < 660，由排名第 2 的 S20 递补。

#### B 校 B-Z1（计划 1 人；控制线 660）

1. **过滤志愿**：S20、S11、S15、S07 均填报 B-Z1。
2. **过滤资格**：S07 不在资格名单，排除；S20、S11、S15 在名单内。
3. **过滤计划控制线**：S15 659 < 660，排除；S20 680、S11 670 达标。
4. **按考核排名**：S20 排名 2，S11 排名 3；S20 在前。
5. **录取**：B-Z1 计划 1 人，录 S20；S11 因满额不录。
   - 余额：1→0。
   - 全局录取顺序：S20=2。
   - 依据 §三.2；U05；R5。

> S20 的 680 分同时高于 A 校控制线 680；这不影响 B 校录取，因为自招按学校分别竞争，S20 只填了 B-Z1。

## 4. 本 case 验证了什么、没验证什么

### 4.1 验证了什么

- 未获资格：S04、S07 分数达标也不能录。
- 未达计划控制线：S10（排名 1）、S15（排名 1）不能录；659 与 660、679 与 680 的低 1 分边界均被覆盖。
- 达标者按校内考核排名竞争：A 校 S18(排名 2) 录、S03(排名 3) 不录；B 校 S20(排名 2) 录、S11(排名 3) 不录。
- 先过滤控制线再排名：A 校排名 1 的 S10 未达线，名额由排名 2 的 S18 获得；B 校排名 1 的 S15 未达线，名额由排名 2 的 S20 获得。
- 自招计划控制线只约束本校自招，不与统一招生梯度混用。

### 4.2 没验证什么

- **考核排名重复**：本 case 假设排名校内唯一且合法；重复排名属于异常输入，由 c11 覆盖，不在本 case 硬凑。
- **自招未满余额结转**：A-Z1、B-Z1 均满额，`carry_out=0`；自招余额转入第三批的口径见 A-03。
- **统一招生梯度与志愿轮次**：本 case 无第二至第四批志愿；由 c02/c03/c04/c10 验证。
- **跨批次排除**：本 case 录取者没有后续志愿，不能证明“录后退出”；由 c06 验证。
- **统计口径差异**：每计划 1 人，末位=最低分；由 c10 验证。

> 结论：c05 的数据足以验证“资格—控制线—考核排名”三层过滤及 679/680、659/660 边界；不足以验证自招余额结转和统一招生规则，未被硬凑进本 case。
